## السيناريو والضوابط

سكريبت scripts/load-test.mjs يتطلب --run-approved؛ النطاق مثبت في الكود ولا يُشغّل تلقائيًا. ملف scratch/performance/STOP أو SIGINT يوقفه. سقف زمني 300 ثانية وسقف طلبات 600، ومهلة 5 ثوانٍ لطلب الحمل و10 ثوانٍ لطلب المراقبة. يوقف عند تعذر المراقبة، RAM متاحة تحت 15%، أو مساحة متاحة تحت 20%، أو اتصالات عند 90% من الحد، أو CPU بمتوسط فوق 85% لمدة نحو دقيقة، أو HTTP 5xx فوق 2% في النافذة، أو p95 فوق ثانيتين لمدة دقيقة، أو 401/403/429، أو ثلاثة أخطاء نقل متتالية.

المراقبة عبر Supabase Metrics API، بعينات قبل المراحل وبعدها (تقريبًا كل دقيقة)، وليست مراقبة لحظية لكل ثانية؛ CPU محسوب من فرق العدادات، وRAM من MemAvailable، ومساحة الأقراص من المساحة المتاحة. زمن p50/p95/p99 مأخوذ من الردود الفعلية، لا عينات التعويض الاصطناعية.
