# قائمة اختيار التخصصات

هذه اختيارات مقترحة لا تُسجل أو تُفعّل تلقائيًا. الكود داخلي لفاميلي كير وليس كود تشخيص أو فوترة أو اعتماد رسمي. يختار المالك التخصص عند توفره ثم يحفظه. يمكن كتابة تخصص آخر وتخصيص الكود.

أسماء التخصصات راجعت قوائم [GMC](https://www.gmc-uk.org/education/standards-guidance-and-curricula/curricula) و[ADA](https://ncrdscb.ada.org/recognized-dental-specialties)، مع إضافة مسميات أقسام عيادات مثل العلاج الطبيعي والتخاطب والتغذية؛ ليست قائمة تنظيمية مصرية موحدة أو حصرًا لكل الفروع. الأكواد من إعداد المشروع.


## اختيارات فاميلي كير الأساسية

حسب صورة المالك: تظهر هذه التخصصات الأربعة عشر في القائمة الأساسية، ومعها «أخرى — إضافة تخصص جديد» للإدخال اليدوي. لا تُضاف تلقائيًا لقاعدة البيانات. القائمة المرجعية الأوسع أدناه محفوظة للمراجعة ولتوليد الأكواد للأسماء المعروفة عند إدخالها يدويًا.
