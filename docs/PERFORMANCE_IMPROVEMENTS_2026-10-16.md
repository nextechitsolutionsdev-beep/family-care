فُصلت وحدات الشاشات باستخدام React.lazy، بما فيها التقييم العام، مع Suspense يبقي إطار التنقل ظاهرًا أثناء فتح الشاشة. حُمّل ملفJavaScript واحد فقط عند تسجيل الدخول في فحص نسخة الإنتاج المحلية؛ شاشات الإدارة والعملاء لا تُحمّل قبل استخدامها. إجمالي كود التطبيق لم يُحذف، بل يؤجل تنزيله.

التحديثات المطلوبة في نفس اللحظة تتشارك دورة قراءة، بما فيها إعادة تنفيذ effect في StrictMode. إذا طلب تحديث أثناء قراءة جارية، تنتظر الطلبات دورة جديدة واحدة بعد الحالية، حتى لا تعرض شاشة ما قبل حفظ عملية مالية. لا تخزين دائم أو TTL أو إعادة استخدام بيانات بين الحسابات. ما زال التطبيق يقرأ كل جداول الدور عند الدخول والتحديث؛ التحميل حسب الشاشة والتصفح من الخادم عمل لاحق يحتاج عقد بيانات واختبارات لكل التقارير، وليس منفذًا هنا.

أسماء السجلات مرتبطة بفهرس في الذاكرة بدل البحث الخطي لكل خلية. البحث العام وصفحة العملاء يفهرسان أكواد التخصص مرة عند تغيير البيانات بدل مسح الأكواد لكل عميل ولكل حرف. نتائج البحث نفسها وأسماء الحقول محفوظة. القياس الاصطناعي محلي ومن تشغيل واحد، لا زمن استجابة قاعدة البيانات ولا ضمان زمن جهاز آخر.

## التحقق

- lint وtypecheck وbuild وفحص عدم تسريب أسرار البناء نجحت.
-4 اختبارات جديدة: مشاركة القراءة، التحديث التالي، إعادة المحاولة بعد الفشل، وطلب تحديث أثناء قراءة بعد حفظ؛ واختبار البحث ضمنها. مضافة إلى npm test.
- فحص دخول الكمبيوتر والهاتف نجح. فحص نسخة الإنتاج المحلية بحساب استقبال حقيقي نجح عبر12 مراجعة (اليوم والعملاء والمتابعات والتخصصات والرسائل والمصروفات بعرض1366x768 و390x844)، بلا خطأ تشغيل أو تجاوز عرض؛28 جدولًا قُرئ كل منها مرة واحدة عند الدخول. اللقطات والنتيجة في output/performance محليًا، مع مراجعة صور اليوم والعميل.
- npm test:11 نجاح و1 فشل عند تسجيل دخول المالك، قبل منطق الاختبار. اختبار شاشات المالك توقف في الدخول لنفس السبب: invalid_credentials لبيانات OWNER_EMAIL/OWNER_PASSWORD المحلية. لم تُضعف الاختبارات أو يُعدّل الحساب. مطلوب بيانات أدمن صالحة لاستكمال تغطية الإدارة والأدوار قبل النشر.
- اختبارات المصروفات والخدمة السريعة تعمل داخل معاملات متراجعة ونجحت، واختبارات المال والمدخلات نجحت. لا ترحيلة مطبقة لهذه التحسينات.

لتشغيل التحقق: npm run lint، npm run typecheck، npm run build، npm test، ثم npx playwright test tests/login.e2e.spec.mjs tests/screens.e2e.spec.mjs بعد تحديث بيانات المالك محليًا في env المتجاهل منGit. npm run preview يعرض البناء محليًا.

الخطوة التالية بعد تغطية الأدمن: فصل جلب الرسائل والتدقيق والتقارير عن اليوم، مع ترقيم صفحات وحساب إجماليات على الخادم دون إسقاط سجلات من الحسابات، ثم مقارنة طلبات وزمن رحلة فعلية. مهلات دورة400 لا تبرر تعديل RLS أو شراء موارد دون دليل يحدد مصدرها.
